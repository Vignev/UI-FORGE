# Theming

UI Forge uses CSS custom properties (CSS variables) for theming, making it easy to customize the look and feel of all components. Simply override the variables in your application's CSS to create your own theme.

## Getting Started

Import the base styles from UI Forge, then override any CSS variables in your application:

```tsx
// App.tsx
import '@ui-forge/react/styles/ui-forge.css';
import './your-theme.css';
```

```css
/* your-theme.css */
:root {
  --uif-primary: #8b5cf6;
  --uif-primary-hover: #7c3aed;
}
```

## Dark Mode

UI Forge automatically supports dark mode. Use the `ThemeProvider` to enable theme switching:

```tsx
import { ThemeProvider, useTheme } from '@ui-forge/react';

function App() {
  return (
    <ThemeProvider defaultTheme="light" enableSystem>
      <YourApp />
    </ThemeProvider>
  );
}

function ThemeToggle() {
  const { theme, toggleTheme } = useTheme();
  return (
    <button onClick={toggleTheme}>
      {theme === 'light' ? 'Dark Mode' : 'Light Mode'}
    </button>
  );
}
```

The `ThemeProvider` sets `data-theme="dark"` on the root element, which activates dark mode CSS variables.

## Best Practices

1. **Only override what you need** - Start with the base theme and only change the variables you want to customize.

2. **Use semantic variables** - Reference semantic variables like `--uif-primary` instead of hardcoded colors in your components.

3. **Test both themes** - Always verify your customizations work in both light and dark mode.

4. **Maintain contrast** - Ensure text remains readable against backgrounds (WCAG AA requires 4.5:1 for normal text).

5. **Use the scale** - Stick to the provided spacing, font size, and radius scales for consistency.
